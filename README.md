# 💻 Portfólio Pessoal | Rafael Fontoura

> Landing page pessoal desenvolvida como atividade da disciplina de **Programação Front End** (MAPA), aplicando na prática os conceitos de **HTML semântico** e **CSS puro**.

<br>

## 📖 Sobre o projeto

A proposta foi construir uma **Landing Page** que apresentasse informações de forma clara, organizada e visualmente atrativa. Além de fixar o conteúdo aprendido, a atividade convida a refletir sobre como quero ser visto como profissional e a organizar essas informações de maneira técnica e criativa.

A página reúne:

* 🙋 Uma seção **Sobre Mim**
* 🛠️ Minhas **Habilidades** técnicas
* 📁 Uma vitrine de **Projetos**
* 🔗 **Redes sociais** e informações de contato

<br>

## 🧰 Tecnologias utilizadas

Projeto feito com HTML e CSS puros, sem frameworks como Bootstrap.

* **HTML5** semântico (header, nav, main, section, article, aside, footer)
* **CSS3** (variáveis, Flexbox, Grid e media queries)
* **Design responsivo**, funcionando bem no computador e no celular
* **Font Awesome** para os ícones das redes sociais
* **Google Fonts** (Archivo, Inter e JetBrains Mono)

<br>

## ✨ Funcionalidades

* ✅ Estrutura totalmente baseada em **HTML semântico**
* ✅ **Menu de navegação** com âncoras que rolam suavemente até cada seção
* ✅ Layout **responsivo** que se adapta a diferentes tamanhos de tela
* ✅ Cards de projeto com efeitos de interação no hover
* ✅ Cuidado com **acessibilidade** (textos alternativos, foco visível pelo teclado e respeito à preferência de menos animação)

3. Abra o arquivo `index.html` no seu navegador. Pronto! 🎉
